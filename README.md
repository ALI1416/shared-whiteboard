# 共享白板（v1.0.0）

HTML5 + Node.js 实现的多人实时协作白板，房间数据全部缓存在服务器内存中，支持 iOS 9 Safari。

预览地址：<http://web.404z.cn:9000/>

> **声明**：本项目由豆包 AI 生成，仅供学习与参考。使用过程中出现的任何问题，作者不承担任何责任。

## 主要功能

- **12 种工具**：抓手（平移画布）、选择（点选 + 框选）、画笔、直线、箭头、矩形、圆形、文本、图片、油漆桶、激光笔
- **协同编辑**：同房间成员实时看到彼此的绘制、选中状态与激光笔光标；撤销 / 重做按 **PS 式单条操作时间线**维护（服务端 / 客户端同一模型，操作记录非全量快照，深度上限 100），**本地立即执行、无需每次操作从服务器获取数据**，撤销 / 重做后只有其他成员收到状态校正（操作人本地已同步）
- **选中变换**：拖动移动、角点缩放（被拖控制点跟随鼠标、对角固定）、顶部圆点旋转；单击旋转圈复位到初始尺寸 / 方向，当前位置保持不变；蓝色编辑框随图案边框一起旋转；**编辑框锚点、线宽、旋转圈固定为屏幕像素大小**（不随画布缩放变化，缩小视图或触屏设备上也不会偏大）
- **框选多选**：空白处拖出选择框批量选中，多选组支持整体移动、缩放、旋转、复位、复制、删除
- **复制 / 删除**：顶部栏「复制」复制一份选中图案并选中副本；「删除」仅选中图案后生效（未选中不删）
- **颜色与样式**：12 个常用色（第一行黑灰浅灰红蓝绿、第二行白棕橙黄紫粉；选中色块带选中框）+ R/G/B 滑块 + 手动输入 hex（仅 `#RRGGBB` / `#RGB`，不再支持 transparent）+ 最近使用；描边 / 填充可分别设色（**仅矩形、圆形显示描边/填充按钮**并支持内部与边框异色）；透明度、线宽、字号可调（**面板按选中类型显隐：图片只透明度、文本只字号、画笔/直线/箭头/矩形/圆形只线宽，未选中全部恢复**；RGB / 透明度 / 字号 / 线宽滑块带统一样式且**已滑过部分渐变着色**，iOS 上轨道与圆点可见可点、**点击轨道直接跳值**、**拖动结束不二次跳值（按下/松开数值一致）**、**切换选中图案时渐变按新值重绘（含 RGB 滑块）**）；置顶 / 上移 / 下移 / 置底调整层次
- **属性实时调整**：选中图案后右侧面板实时调整颜色、透明度、线宽、字号（图片仅透明度），滑块拖动实时预览、松手提交并支持撤销；选中矩形/圆形切「填充」选色后，再选其它图案颜色目标自动回到描边，透明度不归零、新建图案颜色始终可改；**文本调字号同步重算包围盒（选择框随字号变化）**
- **实时创建显示**：画笔 / 直线 / 箭头 / 矩形 / 圆形 / 文本的绘制过程对同房间成员实时显示（绘制中即广播初始形态，完成时提交完整几何）
- **文本内联输入**：文本工具点击画布后直接在画布上输入（无弹窗），默认字号 20（提示文字同字号）；输入框半透明、可拖拽移动、**随内容自动变宽变高且无滚动条**（按文本实际字号测量、高度按行数估算，**单行文本不会误换行/误占两行高**），提交位置按输入框内文字起点计算（左 6px + 上 2px + 首行 0.15 字号），输入即所见；失焦或切换工具自动提交；**双击已有文本（选择工具下）再次进入编辑**（带原文，修改提交后广播更新，清空提交则删除）；文本缩放同步改变字号并设边界（6~400），**越界后继续缩放完全定格（无任何变化）**，文本几何广播携带 fontSize 与 text（远端字号与文字同步）
- **插入图片回选择**：插入图片成功后工具自动回到「选择」，可直接拖动调整；油漆桶点击图片可应用当前透明度；油漆桶对其它图案使用面板当前选中的颜色（矩形/圆形填充 + 保留描边色，画笔/直线/箭头/文本改描边色）
- **共享与权限**：创建房间可设访问密码、指定房间号（大写字母 + 数字）；分享生成可编辑或只读链接（URL 带 `ro=1`）；只读用户仅可查看、缩放、激光笔、分享只读链接与退出
- **房间设置**（创建者点击房间名打开）：重命名白板、修改 / 取消访问密码（修改 / 设置密码后在线访问者被强制退出并提示重新输入密码，改名实时同步到所有成员）；**「只读用户禁用激光笔」**（开启后只读成员激光消息被服务端忽略、激光按钮隐藏，在线只读成员即时生效）；**「可编辑用户禁止编辑（降级为只读）」**（开启后可编辑访客降级为只读、改动消息被拒，在线成员即时生效、新加入成员同样降级，关闭后按基础权限恢复，房主始终不受影响；与激光策略联动，恢复可编辑后激光笔同步恢复）
- **加入预检**：首页加入前先校验房间号与密码，房间不存在或密码错误直接提示，不进入白板页面
- **创建者专属**：名字固定为「房主」、颜色恒为红色；点击房间名打开房间设置弹窗（改名 / 修改访问密码 / 只读禁用激光笔 / 可编辑用户禁止编辑）；退出弹窗内可复制房主链接或删除整个白板（二次确认）
- **导出图片**：顶部栏「导出」按钮把当前白板全部内容按元素包围盒离屏渲染为 PNG 下载（单边超 4096 自动缩小），所有成员可用
- **导入 / 导出配置**：分享弹窗内「导出配置」把所有元素导出为 JSON 文件（房主 / 可编辑者 / 只读者均可用）；「导入配置」仅房主可用，导入前提示将覆盖当前白板全部内容且无法撤销，服务端校验过滤非法元素后全量替换并广播
- **退出白板**：房主 / 访问者 / 只读用户均有「退出」按钮，退出后白板仍保留在服务器上
- **隐藏工具栏**：隐藏所有菜单只留画布，右上角浮层提供「显示工具栏」与「全屏」按钮
- **浏览器全屏**：顶部「全屏」按钮（F11）使用 Fullscreen API，含各前缀降级
- **管理员控制台**：首页「管理员登录」入口进入 `/admin`（HTTP 基本认证，账号密码由启动参数配置）；可查看全部白板（含最后修改时间，有在线访问者的房间显示「现在」）、伪装成房主进入任意白板、删除指定 / 全部白板
- **自动回收**：空白板无访问 1 小时自动删除；有内容白板无访问或修改 7 天自动删除（服务端每 10 分钟巡检一次）

## 运行

服务端使用 Node.js（建议 Node 24+；server.js 与 test/ 无需兼容 iOS 9，仅 public/ 客户端保持 ES5 / iOS 9 兼容）。

使用nvm启动
```bash
# 下载nvm安装脚本
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.7/install.sh | bash
# 加载环境变量
source ~/.bashrc
# 验证nvm
nvm --version
# 安装node24，自带npm
nvm install 24
# 使用node24作为当前版本
nvm use 24
# 设置默认版本（新开终端自动使用node24）
nvm alias default 24
# 全局安装pm2
npm install pm2 -g
# 校验版本
node -v
npm -v
pm2 -v
# 打开项目文件夹
cd shared-whiteboard
# 安装依赖
npm install
# 启动
pm2 start server.js --name "shared-whiteboard" -- --admin-user=admin --admin-pass="admin!" --port=9000
# pm2开机自启
pm2 startup
# 保存配置
pm2 save
```

## iOS 9 兼容说明

- 客户端仅使用 ES5 语法与旧版 Web API（var / function、XMLHttpRequest、WebSocket、FileReader、Canvas 2D），不使用 let/const/箭头函数/模板字符串/fetch/Promise 链；CSS 不使用 Grid、flex `gap`、`inset`，并带 `-webkit-` 前缀
- WebSocket 连接 `/ws` 时不带任何查询参数，打开后在首条消息发送 `hello {room,pwd,key,ro,name}` 完成加入；服务端显式关闭 `perMessageDeflate`（iOS 9 握手缺陷）
- canvas 单边尺寸不超过 4096（按屏幕尺寸自动降档 devicePixelRatio）
- `touchmove` 做 passive 特性检测并显式 `preventDefault`，坐标统一用 `getBoundingClientRect` 计算
- 自定义颜色用 R/G/B 三滑块（iOS 9 不支持 `<input type="color">`）；文本输入直接在画布内联输入（半透明输入框，失焦提交）；图片仅支持相册文件选择（FileReader 压缩后上传）

## 技术要点

- **协同协议**：新增 / 修改 / 删除 / 层次 / 清空等离散操作写入**单条操作时间线**（`history` + `historyIndex`，深度上限 100，新操作截断未来）后广播；撤销 / 重做由客户端本地立即执行（加入时获取全部缓存与时间线），服务端权威执行后仅向其他成员广播状态校正（操作人无需校正）；操作记录结构：`{t:'add',el,i}` / `{t:'upd',id,before,after}` / `{t:'del',el,i}` / `{t:'clear',els}` / `{t:'ord',id,from,to}`，服务端 / 客户端同构
- **选中状态广播**：`sel` / `selection` 消息携带完整选中 id 数组（含多选），让其他成员（含只读访问者）看到当前编辑者在编辑哪些图案
- **激光笔**：`laser` 消息只广播给其他成员（发起者本地渲染，不自收）；轨迹约 1.5 秒渐隐，松开后不立即消失，再次点击立即清掉残留；颜色取用户标记颜色（房主恒红）；房间设置「只读用户禁用激光笔」开启时，服务端忽略只读成员的 laser 消息（防 URL 篡改）
- **绘制性能**：绘制过程本地实时渲染，缩放 / 平移 / 激光笔消息节流发送
- **统一锚点缩放**：所有图案类型（笔 / 直线 / 箭头 / 矩形 / 圆形 / 文本 / 图片）按「被拖角点 → 对角锚点」距离等比缩放，按下时几何为基准，连续拖动不复合；直线 / 箭头仅两端锚点参与缩放，其它锚点不强制吸附
- **权限**：只读权限由分享链接 `ro=1` 决定（创建者始终可编辑）；房间设置两项策略服务端权威：`noLaserRO`（只读禁用激光笔）、`forceRO`（可编辑访客降级为只读，记录基础权限 `baseReadonly` 供恢复）；服务端拒绝只读连接的一切改动类消息，消息与元素字段均有白名单校验；只读用户只能生成只读链接
- **管理员**：账号密码常量时间比较防时序攻击；房间列表返回 `ownerKey` 供伪装房主进入；删除白板复用创建者同一套 `deleteRoom`（广播 `room_deleted` 并断开所有成员）
